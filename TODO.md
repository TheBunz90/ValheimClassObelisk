## Done

- [x] **Class XP persists across character deletion / reuse of a character name.** Root cause (confirmed via decompiling Valheim's own code): the main-menu character-preview model (`FejdStartup.SetupCharacterPreview`) is instantiated with `ZNetView` deliberately disabled, so it never gets a real ZDO and `Player.GetPlayerID()` always returns 0 for it - yet both browsing the character list and finishing "New Character" route through the same `Player.Save`/`Player.Load` calls our mod patches. That let one real character's class data get cached in memory under the shared key `0` while previewing it in the menu, then get baked straight into the next new character's first save - nothing to do with names or deletion, the leak happens in memory at menu time. Fixed by skipping both `Player_Save_Patch` and `Player_Load_Patch` whenever `GetPlayerID() == 0`. **Note:** this only stops the leak going forward - any character save that already inherited wrong XP before this fix stays wrong; no retroactive repair was done.
- [x] **Second class slot (unlocked at level 50) can't actually be selected.** Root cause: the only wired-up selection method always replaced the active class list with one entry, and the correctly-eligibility-aware add/remove methods existed but were never called; the Obelisk UI was also a single-select radio pattern with no way to pick a second class at all. Fixed by adding `PlayerClassManager.ActivateClass`/`DeactivateClass` (add-if-room, swap if only 1 slot unlocked, block if both of 2 slots are full) and reworking the Obelisk panel: class buttons preview descriptions (green-highlighted when active), and a dynamic Activate/Deactivate button + italic "class limit reached" hint at the bottom drives the actual state change - all in-panel, since MessageHud toasts render underneath the panel and are invisible while it's open. See CHANGELOG.md (Unreleased).
- [x] **Remove extra notifications.** Catalogued every `player.Message` call in the mod (16 total). Removed the 8 that fired on or near every hit (chance-gated 10-30%, so still frequent): the universal "Weapon Mastery: +X% damage!" toast, Sword Master's Fencer's Footwork/Weakpoint, Archer's Long Shot/Adrenaline Rush/Magic Shot, Crusher's Cold Steel, and Assassin's Venom Applied - the underlying effects (damage bonuses, stamina restore, etc.) are unchanged, only the toast text is gone. Kept the per-kill "+X XP" toast and the rare, milestone/skill-gated ones (Level Up!, Perk Unlocked!, Riposte, Arrow Slinger buff, Thundering Blow!). Also deleted `ArcherPerkManager.ShouldConsumeArrow`, dead code found during the pass (never called - the reachable Magic Shot logic lives in `Inventory_RemoveItem_MagicShot_PreFix`). See CHANGELOG.md (Unreleased).
